# Density Functions in Debug Screen

This mod is a development tool for worldgen developers that shows the values of a configurable list of density functions in the debug screen (F3 menu).

![Screenshot showing the values of several density functions along with their names in the upper left corner of the screen](https://cdn.modrinth.com/data/2RlhPTZI/images/165d06789eed871fea86d2e4bee9c1a9ddfb8320.png)

Features an extensive configuration file allowing customization of which density functions to evaluate (possibly only displaying them when in certain dimensions) as well as styling options.

Because this mod is solely intended as a development tool, this mod is only known to work on and only supports singleplayer.
